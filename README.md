# Ministry of Trade and Industry - Frontend Application

A React.js application for the Ministry of Trade and Industry of Central African Republic, built with Material UI.

## Features

- Landing page with welcome message
- Getting started guide
- User dashboard with featured services
- Application history tracking
- Multi-step application form
- Professional navigation and user interface

## Installation

```bash
npm install
```

## Running the Application

```bash
npm start
```

The application will open at [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
```

## Technologies Used

- React.js
- Material UI (MUI)
- React Router
- JavaScript (ES6+)
